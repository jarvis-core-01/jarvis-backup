Privacy policy

JARVIS is a private assistant used only by its owner, on the owner's own Google account.

What it accesses

  • Gmail: reads mail, and creates, lists and deletes drafts. It never sends mail.
  • Google Calendar: reads events, and creates, changes and deletes events when the owner asks.
  • Google Drive: searches and reads files (read-only).
  • Google Contacts: reads contacts (read-only) into the assistant's memory on the owner's server.

How the data is used

Data from Google is used only to answer the owner's own requests. To do that, the relevant parts are sent to the AI model that writes the answers (Anthropic's Claude API). It is stored only on the owner's server, and is never sold, shared with anyone else, or used for advertising.

JARVIS's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access

Access can be removed at any time at myaccount.google.com/permissions.
