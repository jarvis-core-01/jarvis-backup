Privacy policy

JARVIS Backup is a private tool used only by its owner, to back up the owner's own home server to the owner's own Google Drive.

What it accesses

It uses the Google Drive scope drive.file, so it can only see and change the files it created itself. It cannot read any other files in the Drive.

What it stores

The backups are encrypted on the owner's server before upload. They are stored only in the owner's Google Drive and are never shared, sold or sent to anyone else.

Revoking access

Access can be removed at any time at myaccount.google.com/permissions.
